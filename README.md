# WorkSquare Fullstack Developer Vetting Task

Welcome! This task assesses your ability to build a complete housing listings app with a backend API and frontend interface.

---

## Objective

Build a fullstack housing listing app that allows users to browse available properties.

---

## Requirements

### Backend:
- Use any of: Node.js (Express), Laravel, Django, or Flask
- Serve listings from a `listings.json` file
- RESTful API with:
  - Paginated listing route
  - Filter by location or property type
  - Get listing by ID
  - JWT-protected route
  - Rate limiting
  - Middleware for logging
  - API documentation (Swagger/OpenAPI)

### Frontend:
- Use any of: React, Vue.js, or Angular
- Consume your backend API
- Responsive UI to display listings
- Filter/search interface
- Loading and empty states
- Use Tailwind, CSS Modules, or equivalent

---

## What We’re Looking For

- Clean fullstack architecture
- Separation of concerns
- API and frontend integration
- Git best practices
- UI/UX quality

---

## Submission

1. **Fork** this repo
2. Build both frontend and backend inside (separate folders or structure)
3. Push your changes
4. Share your forked repo link via email

🕒 **Deadline**: 72 hours after receiving this task

---

## 📝 Note

You’ll receive the `listings.json` data separately. Please create a file in your project and paste the data to use it locally.
